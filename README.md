# Money

Money é um app de finanças pessoais feito com React, TypeScript, Vite e Supabase.

## Recursos

- Dashboard mensal com saldo, receitas, despesas, economia e gráficos.
- Cadastro de receitas e despesas com categoria, meio de pagamento, data, recorrência e notas.
- Histórico com busca, filtros, ordenação, paginação e exportação CSV.
- Orçamentos por categoria e por mês.
- Metas financeiras com aportes e cálculo de esforço mensal.
- Relatórios anuais e impressão em PDF.
- Tema claro/escuro, categorias e meios de pagamento configuráveis.
- Backup JSON para exportação e importação.

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

## Supabase

O arquivo `supabase_schema.sql` contém as tabelas e políticas RLS esperadas pelo app.
